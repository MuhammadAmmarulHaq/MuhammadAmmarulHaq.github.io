Every box starts the same way for me. These are the tools that survived a year of use.

| tool | what i use it for | the line i type most |
|---|---|---|
| nmap | port and service discovery | `nmap -sC -sV -p- --min-rate 5000 target` |
| ffuf | content and vhost discovery | `ffuf -u http://target/FUZZ -w wordlist` |
| burp | request tampering, auth logic | proxy intercept plus repeater |
| netexec | smb, ldap, winrm across a subnet | `nxc smb 10.10.10.0/24` |
| bloodhound | ad relationship mapping | collect then shortest path from owned |
| impacket | kerberos and smb primitives | `impacket-secretsdump` |
| linpeas | quick local enumeration | pipe to a file, read it after |

## notes on the workflow

One folder per box. Inside it: `nmap/`, `loot/`, `notes.md`. The notes file is written
while working, not after, because the useful detail is always the thing i almost skipped.

```bash
$ mkdir -p boxes/example/{nmap,loot}
$ cd boxes/example
```

## what got dropped

Heavy frameworks that hide the command being run. If i cannot retype it from memory,
i do not learn anything from it.
